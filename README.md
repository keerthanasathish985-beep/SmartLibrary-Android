# SmartLibrary Android

SmartLibrary is a digital library management application designed to make accessing and managing library resources easier through a modern mobile interface.

## 🚀 Features

- 📚 Browse and explore library resources
- 🔐 User login and authentication
- 💺 Live seat availability
- 📱 Android application support
- 🤖 AI Assistant interface
- 📷 QR-based student/library features
- 👤 Student and admin interfaces

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Capacitor
- Android
- Gradle
- Firebase Authentication
